## Estimates

Regarding the **estimates** that you did for practical tasks...

### How was your estimate accuracy usually?

My estimate accuracy was generally low. I often copied similar code from previous practicals and modified parameters 
based on past experience, so I usually overestimated the amount of time needed to complete tasks. However, this habit 
sometimes caused more errors or made me miss some details.

### How did your estimate accuracy improve or change during the course of the subject?

Overall, my estimate accuracy did not improve significantly during the course. Although copying and reusing code helped
speed up development in some cases, it also caused unexpected problems such as type errors or incomplete changes. These 
issues made it difficult to predict the actual time required for a task, especially in larger projects where values 
needed to be imported from other files. In such cases, finding and updating the same code or variable names across 
multiple files was often time-consuming and sometimes frustrating.
### What did you learn from doing these estimates?

I learned that reusing code does not always mean saving time. Even when starting from a similar solution, careful 
checking and testing are still required. The estimation process helped me become more aware of how small mistakes or 
overlooked details can affect the final workload.

## Code Reviews

### What have you learned from being reviewed by other people?

From being reviewed by other people, I learned that small issues are easy to overlook when reviewing my own code. Other 
students often noticed naming or formatting issues that I did not pay much attention to. This helped me improve the 
readability and consistency of my code.

### What have you learned from doing code reviews of other people?

By reviewing other students’ code, I learned how to read code more carefully and think about different ways to solve 
the same problem. Even when I did not find many errors, reviewing other code helped me better understand  different 
coding styles.
